# `@sunflower0305/claude-proxy` v1.3.1

Patch release of `claude-proxy`, published as `@sunflower0305/claude-proxy`.

## Highlights

- the default Qwen upstream model is now `qwen3.7-plus`
- the default MiniMax upstream model is now `minimax-m3`
- README and `.env.example` reflect the upgraded provider defaults

## Upgrade Notes

Existing explicit model overrides keep working. If you have `QWEN_MODEL` or `MINIMAX_MODEL` set in your environment, those values continue to take precedence over the package defaults.

To use the new defaults, remove old overrides such as:

```dotenv
QWEN_MODEL=qwen-plus
MINIMAX_MODEL=minimax-m2.7-highspeed
```

or set the upgraded models explicitly:

```dotenv
QWEN_MODEL=qwen3.7-plus
MINIMAX_MODEL=minimax-m3
```

## Installation

```bash
npx @sunflower0305/claude-proxy
```

or:

```bash
npm install -g @sunflower0305/claude-proxy
claude-proxy
```
